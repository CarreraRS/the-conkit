## 🇹🇭 ภาษาไทย

> **เกมนี้เป็นส่วนหนึ่งของรายวิชา Game Development**

**The ConKit** คือโปรเจกต์เกมแนว 2D ที่ผมสร้างขึ้นด้วย **Godot Engine** โดยเป้าหมายหลักของการพัฒนาคือการทดลอง **"ยัดฟีเจอร์ใหม่ๆ และระบบแปลกๆ"** เข้ามาเพื่อท้าทายและพัฒนาทักษะในการเขียนเกมของตัวเอง หากพบเจอบั๊ก ข้อผิดพลาด หรือระบบที่ไม่สมบูรณ์ประการใด ผมต้องขออภัยมา ณ ที่นี้ด้วยครับ 🙏

### 🕹️ รูปแบบการเล่น (Gameplay)

ตัวเกมแบ่งออกเป็น **3 ด่านใหญ่** ที่เสนอสไตล์การเล่นที่หลากหลาย:

* **ด่าน 1 & ด่าน 2:** **2D Side-scrolling Action** — เดินลุยด้านข้าง ตะลุยด่าน ต่อสู้กับมอนสเตอร์รายทาง และจัดการบอสประจำด่าน
* **ด่าน 3:** **2D Side-scrolling Auto Runner** — เปลี่ยนฟีลมาเป็นแนววิ่งอัตโนมัติ วัดไหวพริบและความไวในการหลบสิ่งกีดขวางสุดท้าทาย

### 🛠️ Engine & Tools

* **Engine:** Godot Engine
* **Genre:** 2D Side-scrolling / Auto Runner

## 🇬🇧 English Version

> **A project developed for a Game Development course.**

**The ConKit** is a 2D action game created using **Godot Engine**. The primary goal of this project was to experiment with **new features and unique mechanics** to challenge myself and level up my game development skills.

Since this was a learning journey and experimental project, you might encounter a few bugs or unpolished mechanics—I sincerely apologize for any issues and appreciate your understanding! 🙏

### 🕹️ Gameplay Overview

The game features **3 unique stages** with distinct gameplay mechanics:

* **Stage 1 & Stage 2:** **2D Side-Scrolling Action** — Classic side-scrolling combat, defeat various monsters along the path, and overcome challenging boss fights.
* **Stage 3:** **2D Side-Scrolling Auto Runner** — A fast-paced runner segment that tests your reflexes as you dodge obstacles.

### 🛠️ Engine & Tools

* **Engine:** Godot Engine
* **Genre:** 2D Side-Scrolling / Auto Runner
